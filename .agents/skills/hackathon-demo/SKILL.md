# Demo Readiness

1. Identify the one user journey judges must see.
2. Verify the app starts from documented commands on a clean environment.
3. Check required environment variables and service health before the demo.
4. Prepare safe, reproducible demo data; do not expose real user information.
5. Exercise the full flow, including at least one failure and recovery path.
6. Remove debug overlays, test credentials, and accidental personal data.
7. Prepare a 2–3 minute narrative: problem, solution, live flow, technical differentiator, impact.
8. Prepare a fallback recording or screenshots if network-dependent services fail.
9. Keep claims aligned with implemented and verified behavior.
