## Gemini CLI workflow
- Treat `AGENTS.md` as the canonical engineering contract.
- Inspect the repository and git status before editing.
- For complex tasks, use plan mode first and break work into independently verifiable steps.
- Use shared skills from `.agents/skills/` when relevant.
- If another agent is working in parallel, confirm file ownership and interfaces before editing.
- Verify the final diff and run the narrowest useful tests, then broader checks when practical.
